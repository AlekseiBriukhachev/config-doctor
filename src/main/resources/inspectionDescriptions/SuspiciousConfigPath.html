Reports YAML property paths that look like an accidental extra nesting level or duplicated segment, such as spring.datasource.datasource.url when the project already contains spring.datasource.url.

The inspection compares property paths extracted from Spring Boot configuration files and warns only when removing one nested segment produces an existing property elsewhere in the project. This helps catch valid YAML that still creates the wrong configuration key and can hide bugs until runtime.

Example: 


spring:
  datasource:
    datasource:
      url: jdbc:postgresql://localhost/db

This is suspicious because the same project typically defines: 


spring:
  datasource:
    url: jdbc:postgresql://localhost/db

The warning is intended for real configuration mistakes, not generic YAML formatting issues.
